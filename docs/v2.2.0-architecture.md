# ZYLO v2.2.0 — Architecture Specification

## 1. Overview
ZYLO v2.2.0 establishes complete architectural parity between Android (`composeApp`, `androidApp`) and Web (`website/`).

## 2. Core Domains & Services
- **Official Web Domain**: `https://zyloweb.vercel.app`
- **Release Verification & Metadata**:
  - Distinguishes Theatrical Release Date from Official OTT/Digital Release Date.
  - States: `Upcoming Theatrical`, `In Theatres`, `OTT Unannounced`, `OTT Scheduled`, `Digitally Available`.
  - Disables Play/Download buttons for strictly theatrical or unreleased movies, showing `Remind Me` and dual countdowns.
- **Playback Architecture**:
  - **Android**: Jetpack Media3 (ExoPlayer) with custom `IntelligentLoadControl` targeting up to ~100s forward buffer, multi-track HLS audio selector (Hindi/South/English), and safe-area insets.
  - **Website**: Multi-engine player: native HLS.js for direct CORS-compliant media, remux bridge for transcode, and seamless iframe container for embed providers.
- **Regional Catalogs**:
  - Live TMDB/Trakt metadata integration for Punjabi, Bollywood, South Indian (Tamil, Telugu, Malayalam, Kannada), Hollywood.
- **Deep Linking & Sharing**:
  - Universal domain: `https://zyloweb.vercel.app/movie/{id}`, `https://zyloweb.vercel.app/series/{id}/{s}/{e}`, `https://zyloweb.vercel.app/party/{roomCode}`.
- **AniDash Integration Contract**:
  - Explicit package intent target `com.anidash.app` with extras: `anime_id`, `anime_title`, `season_number`, `episode_number`.
  - Official download fallback: `https://github.com/anshdeepofficial1/AniDash/releases`.
